# Automated Backup & Data Recovery System (Topic 5A)

**Course:** Operating Systems & Operating Systems Practicum (Semester Ganjil 2026/2027)
**Topic:** 5A — Sistem Otomasi Backup dan Pemulihan Data Linux

* `scripts/` — Shell scripts for backup, verification, locking, and restoration.
* `config/` — Configuration files and role/permission templates.
* `tests/` — Positive/negative test cases and dummy datasets.
* `docs/` — Technical documentation and main OS theory report.
* `evidence/` — Terminal outputs, exit statuses, and checksum proofs.
* `logs/` — Runtime operational logs.
* `output/` — Generated report (`laporan.txt`) mounted read-only to Docker.
